# University of Gibraltar: List and Dictionary Exercises

<img src="logo.png" alt="University of Gibraltar logo" width="180">

This exercise set is designed for students at the University of Gibraltar. It focuses on working with Python lists and dictionaries, which are foundational to almost every real-world program.

> Make sure you understand how to use lists and dictionaries. Can you give
> three ways that lists and dictionaries are similar, and three ways that they
> are different?

This repository contains a range of exercises involving data stored in lists, dictionaries, lists of dictionaries, and dictionaries of dictionaries.

In each exercise, a Python script contains sample data and a set of tasks to complete using that data. Before starting, make sure you can clearly describe the structure of the data and the expected output.

## Student requirement

Each student should choose one or two exercises from the set and complete them as their own work.

After completing the selected exercise(s), the student should submit the solution in their own GitHub repository. The repository should contain the relevant Python files and a clear explanation of the work completed.

## Suggested order

Students may work through the exercises in the following order:

*  `radio_freq.py` (data embedded in the script)
*  `rgb_colours.py` (data embedded in the script)
*  `exam_results.py` (data embedded in the script)
*  `football_results.py` (data embedded in the script)
*  `bill_splitting.py` (data embedded in the script)
*  `conference_schedule.py` (data embedded in the script)
*  `presidents.py` (external Python data in `presidents_data.py`)
*  `browser_stats.py` (external Python data in `browser_stats_data.py`)
*  `shop_orders.py` (external JSON data in `shop_orders.json`)
*  `bike_share.py` (external JSON data in `bike_share.json`)
